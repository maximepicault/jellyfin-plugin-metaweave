Personne

Comment lire UNE personne dans l'API. Les personnes se saisissent ensuite par identifiant dans l'écran Personnes. Un champ vide est ignoré. Plusieurs chemins séparés par || : le premier qui existe et n'est pas vide est utilisé (par exemple title || name).

{id} est remplacé par l'identifiant de la personne dans cette API. Par exemple /people/{id}, ou une recherche : /search?user={id}.
Si l'API répond par une liste (par exemple une recherche qui renvoie un seul élément), désignez son premier élément avec [0] : [0].name pour une liste à la racine, results[0].name pour une liste dans un objet. Les champs ci-dessous suivent la même règle.
Une adresse complète est utilisée telle quelle. Un chemin (/abc123.jpg) est complété avec le champ ci-dessous, ou avec l'URL de base de l'API s'il est vide.
Le chemin renvoyé par l'API est ajouté à la suite : https://images.example.com/p/w185 + /abc123.jpg. Pour un autre format, écrivez {value} à l'endroit du chemin : https://images.example.com/{value}?w=200.

Contenu

Séries, saisons et épisodes de cette source. Chaque élément a un tag {préfixe-ID} à mettre dans le nom de son dossier (série, saison) ou de son fichier (épisode). Un épisode sans fichier apparaît comme épisode manquant.
