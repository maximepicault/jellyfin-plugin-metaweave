Épisodes manquants

Configuration du plugin
Cette page compare la liste d'épisodes renvoyée par chaque source (endpoint « Liste des épisodes ») aux fichiers {préfixe-ID} présents dans vos saisons. Seules les saisons dont le dossier porte le tag d'une source avec cet endpoint configuré sont analysées. « Réanalyser sans cache » retélécharge aussi les miniatures et les aperçus.
