Personnes

L'annuaire du casting, commun à toutes les sources. Chaque personne peut venir d'une ou plusieurs API (un identifiant par source) ou être saisie à la main. Elles s'ajoutent ensuite à la distribution des épisodes : dans la source pour une source locale, dans l'onglet « Distribution des épisodes d'API » pour une source API.

Le casting est désactivé dans les réglages du plugin : les personnes et les distributions ne sont pas envoyées à Jellyfin tant que « Importer le casting » est coupé. Ouvrir les réglages

Ajouter une personne

Aucune source de personnes n'est configurée. Ajoutez-en une (type « Source de personnes »), ou utilisez la saisie manuelle.

Ajoutez une distribution aux épisodes qui viennent d'une source API (ceux d'une source locale se règlent dans la source). L'API n'est pas modifiée : la distribution est rattachée au tag de l'épisode et s'ajoute à son casting éventuel, sans doublon.
