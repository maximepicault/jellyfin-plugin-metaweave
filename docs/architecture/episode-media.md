# Preview video of local episodes and chapters

> Detail moved out of `CLAUDE.md` to keep the always-loaded file small. Read it when touching uploaded preview videos or episode chapters (`ChapterService`, `ChapterParser`). `CLAUDE.md` still holds the rules that apply everywhere.

**Preview video of a local episode (uploaded file or link).** `LocalEpisode.PreviewUrl` is a web address OR `local://video/{dataId}/{file}` (stored like images: `local-sources/{dataId}-videos/{node}-{random}.mp4|webm|mkv`, 500 MB, `LocalSourceStore.SaveVideoAsync` streams the body to a `.part` file, reads the type from the first 64 bytes with `DetectVideo` (MP4/MOV `ftyp`, EBML → WebM or MKV) and renames it; a refusal happens before anything is written). `POST CustomMetadata/Local/{dataId}/Video?node=` (admin, `RequestSizeLimit` lifts ASP.NET's 30 MB default: tested with 45 MB) and the **anonymous** `GET …/Video/{file}` (`PhysicalFile(enableRangeProcessing: true)`; only files matching `^[A-Za-z0-9_-]{1,60}\.(mp4|webm|mkv)$` of the plugin's folder): both the editor's player and Jellyfin read it, neither sends a token. `LocalSourceStore.Serve` turns the local address into `{GetLocalApiUrl("127.0.0.1")}/CustomMetadata/Local/{dataId}/Video/{file}` (`JellyfinVideoUrl`, address injected in the constructor like `PeopleStore`'s), so everything downstream (missing-episode cache hash, `SyncPreviewAsync`, `PreviewMapper.GetPreviewTrailers`, which identifies a trailer by an http(s) Path) is unchanged: an uploaded preview is just a link to this server. `Save` prunes unreferenced videos older than one day (`PruneVideos`), `Delete` renames the folder to `.deleted`. Editor: `videoField` / `uploadVideo` (XMLHttpRequest for the progress; `fetch` has none) in the Images sub-tab. As for links, only missing (virtual) episodes get the trailer. Test: `tools/ui-test/local-preview-video-real.mjs <url> <out_dir>` (ffmpeg on the host makes the test video; 21 checks, REST + Playwright; restores config and data).

**Chapters (time codes) of episodes.** `CustomMetadataResponse.Chapters` (`ChapterMark {Seconds, Title}`), mapped by `JsonFieldMapper.GetChapters` from `FieldMapping.ChaptersArray` (list of objects with `ChapterTime` / `ChapterTitle`, list of "12:34 Titre" texts, or one multi-line text; empty = off; defaults `chapters` / `time` / `title`, so an existing source whose API already has a `chapters` field gets them), `ChapterEnd` (optional path of each chapter's end, same forms; EMPTY by default for an API source, and forced to `end` for a local source in `CustomApiClient.ResolveEndpoint`, which serves it that way, even for sources saved before) and `ChapterTimeUnit` (`seconds`|`milliseconds`: only for BARE numbers) and `ChaptersFromOverview` (fallback: lines of the synopsis starting with a time code, two at least). `Services/ChapterParser` is the single time-code parser: it is NOT `DurationParser` (that one refuses zero, a chapter at `0:00` / `0` is valid; and it does not read `6m12s`), 37 cases in the scratch table that was used to write it (mm:ss, hh:mm:ss, fractions, seconds, units, ISO, rejects: minutes ≥ 60 in hh:mm:ss, seconds ≥ 60, > 24 h = a unit mistake). `ParseLines(text, anyNumber)`: `anyNumber` false for a synopsis (a line starting with a year must not become a chapter), true for the local field. **A metadata provider cannot return chapters and Jellyfin's media probe ERASES them during a refresh** (observed: `saved … (before: 0)` after a second full refresh), so `CustomEpisodeProvider` only calls `ChapterService.Remember(path, marks)` and `ChapterService` (an `IHostedService`, `AddHostedService` in the registrator) listens to `ILibraryManager.ItemUpdated/ItemAdded`: for an episode with a file whose path was remembered (30 min) it writes `IChapterManager.SaveChapters` when the stored chapters differ (Jellyfin has a START per chapter and no end: `ChapterParser.WithGaps` adds a chapter named `Hors chapitre` at the END of a chapter that stops more than 0.5 s before the next start, or before the runtime for the last; `ChapterMark.EndSeconds` is cut at the next start (overlap) and ignored when ≤ the start; ranges `0:00-12:34 Titre` in lines, regexes `ColonLine` / `AnyLine`, where a unit must not start a word: `359 Suite` is 359 + "Suite") (idempotent: the event fires several times per refresh), dropping a time code past `RunTimeTicks`, and writing nothing while the length is unknown (Jellyfin 12 drops every chapter then, which would erase the stored ones; the probe raises another update). A virtual (missing) episode has no video: `ChapterText.AppendToOverview` adds a "Repères" list to its synopsis, unless the synopsis already lists the time codes. `MetadataMerger` copies carry `Chapters` (a bundled file keeps its FIRST id's chapters), `MergeOverride`: local chapters replace the API's. Local episodes: `LocalEpisode.Chapters` is the typed text, served as `chapters: [{time (seconds), title}]` (default mapping). Test: `tools/ui-test/chapters-real.mjs <url> <out_dir>` (16 checks; the mock API serves `CHAPTERS` for d1v1 / d1v3 and time codes in the d1v2 synopsis).
